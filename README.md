# DNA GC Content Analysis

## Aim
The aim of this project is to calculate the GC percentage of a DNA sequence using Python.

## Introduction
DNA contains four main bases: adenine (A), thymine (T), guanine (G), and cytosine (C). GC percentage represents the proportion of G and C bases in a DNA sequence.

## Formula
GC percentage = ((Number of G bases + Number of C bases) / Total number of bases) × 100

## Example
DNA sequence: ATGCGCTA

Total bases: 8
G bases: 2
C bases: 2

GC percentage: 50%
